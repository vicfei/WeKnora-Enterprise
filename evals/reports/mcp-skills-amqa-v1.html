3. Privora 金融数据接入（E4）

接入链：令牌 introspect（active，读权限面覆盖 dataasset/investment/dashboard/schedule）→ ClawHub 注册 → install（installer agent ~50s，快照入 g 代镜像）→ 技能层 env secrets （PATCH /sandbox-configs/:id/skills/:skillId {"envs":{LG_AGENT_BASE_URL,LG_AGENT_TOKEN}}）→ agent 消费

排雷（重要）：技能声明 env 的正确配置位是技能行 envs（UI 的"设置→沙箱 secrets"）， 沙箱 config.env_vars 不满足 execute_skill_script 的校验（只对 shell_exec 生效）。分层序： 管理员层 < 用户 config 层 < 用户技能层（mine beat workspace's），用户层可经 /me/env-vars 或 shell_exec(skill_name, env) 自助写入。实验后已撤沙箱级 env_vars，令牌只走技能层（最小暴露面）。

实测（60.8s，6 步 API 调用）：贵州茅台 600519 收盘 1272.75/−0.41%（含 OHLC/成交额）、 易方达蓝筹 005827 净值 1.4809/−0.6107%。独立交叉验证：腾讯行情接口（qt.gtimg.cn）同字段逐项一致； agent 另用 Privora 实时镜像端点自复核。订阅模型说明：marketplace 资产需 subscribe-and-read 预设 scope， 默认 read-data 不含。
